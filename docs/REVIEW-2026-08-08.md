## 4. 信任边界声明

写库 gate 的 role 校验依赖调用方自报 `source`（如 `agent:x|role:parent`），子 Agent
理论上可伪造 role:parent 绕过权限意图。**这是 MCP 协议层信任模型边界**，非代码 bug：
- 缓解：`\b` 边界已加；README 已标注
- 根治：平台层（Hermes）在 call_tool 入口强制注入真实 role，禁止 Agent 自带 source
- 状态：记录待平台层处理（v2 §10.3 待验证问题 1 同类）
